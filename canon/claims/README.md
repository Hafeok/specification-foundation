# canon/claims/

Claim records: one YAML file per claim, `SF-<area>-<nn>`, format v1 as implemented by
`scripts/validate-claims.py`, which CI runs over this directory and which fails the build on any
violation — falsifier presence at every live status among them.

**Empty as at 2026-09-01, and ruled so, not merely so far.** Per `CG-R-14` the seed's canon
artefacts file as prose, because none yet carries a falsifier; each carries a dated commitment to
convert to numbered claim records **here** when the falsifier it awaits lands. The conversion
commitments are in the artefacts' filing records under `canon/`.

The `SF-` identifier space is programme-scoped and stable (`CG-rule-07`): never reused, never
renumbered, unique across the programme.
