# evidence/

Evidence about propositions in the canon. **Not canon**, and never promoted to it by filing here.

The distinction is the canon boundary made physical: a pre-registration, a run record or an
assessment is an observation *about* a claim, and it lives on the opposite side of the path from
the claim it bears on. A validator can then check the boundary by path instead of by judgement.
